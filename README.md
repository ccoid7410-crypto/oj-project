# Durunuri OJ

충북과학고 동아리에서 사용하기 위해 개발한 자체 온라인 저지 시스템입니다.

기존 HustOJ를 설치하는 대신, 온라인 저지의 내부 구조를 직접 구현하고 자유롭게 확장해 보고자 시작했습니다. 단순한 문제 제출과 채점을 넘어 문제 출제·검토, 대회 운영, 권한 관리, 커뮤니티, 동아리 홈페이지 연동 등 다양한 개발과 연구를 수행할 수 있는 기반을 만드는 것을 목표로 합니다.

현재 프로젝트는 개발 중이며, 기능과 구조가 계속 변경될 수 있습니다.

문제는 일반 정답 비교형뿐 아니라 정확도/최적화 점수형과 줄 단위 인터랙티브형을 지원하며,
문제별 허용 언어·컴파일 옵션과 레이팅에 반영하지 않는 연습 문제를 설정할 수 있습니다.
세부 채점 규칙은 [JUDGING_TYPES.md](./JUDGING_TYPES.md)에 정리돼 있습니다.

채점기 VM 분리와 프론트 인터체인저 전환의 실제 진행 상태는
[DEPLOYMENT_PHASES.md](./DEPLOYMENT_PHASES.md)를 참고하세요.

## 개발 방침

이 저지는 채점/문제 관리라는 본연의 기능에 집중합니다. 오답 시 영상 재생처럼 채점과 무관한
장난성·부가 기능은 명시적으로 요청받기 전까지 추가하지 않습니다 (AI 에이전트 지침은
[CLAUDE.md](./CLAUDE.md) 참고).
